# Dữ liệu

Thư mục này **không chứa dataset lớn**. Theo yêu cầu nộp bài, dữ liệu được chia sẻ bằng liên kết riêng, không nằm trong file zip mã nguồn.

## Hiện trạng

| Mục | Trạng thái |
|---|---|
| Tập tài liệu để chạy thực nghiệm | **Chưa có.** Chưa chọn nguồn. |
| Tập có nhãn lĩnh vực để huấn luyện bộ phân loại | **Chưa có.** Chưa chọn nguồn, chưa kiểm tra giấy phép. |
| Bản tóm tắt tham chiếu | **Chưa có.** Cần tự viết bằng tay cho từng tài liệu thử nghiệm. |
| `sample.pdf`, `sample2.pdf` | Tài liệu mẫu dùng khi phát triển. Cần xác nhận bạn có quyền chia sẻ trước khi nộp. |
