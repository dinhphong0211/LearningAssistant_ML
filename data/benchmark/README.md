# Bộ tài liệu thử nghiệm

Đặt tài liệu và bản tóm tắt tham chiếu vào đây. Quy ước tên và cách chạy: xem `docs/BENCHMARK.md`.

- Tài liệu: `ten.pdf` / `ten.docx` / `ten.pptx` / `ten.txt`
- Tham chiếu do người viết: `ten.ref.txt`

Trước khi đưa tài liệu vào thư mục này, hãy ghi nguồn và giấy phép vào `data/README.md`. **Đừng đưa lên GitHub tài liệu có bản quyền không rõ quyền sử dụng.**
